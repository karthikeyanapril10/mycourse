📚 Fundamentals Refresher

Big O Notation (5 Minutes)

Time Complexity:

O(1)        - Constant (hash lookup)
O(log n)    - Logarithmic (binary search)
O(n)        - Linear (single loop)
O(n log n)  - Linearithmic (merge sort)
O(n²)       - Quadratic (nested loops)
O(2^n)      - Exponential (recursive fibonacci)

Space Complexity:

O(1)   - In-place (no extra space)
O(n)   - Linear (extra array/hash)
O(n²)  - Quadratic (2D matrix)

Quick Rules:
- Drop constants: O(2n) → O(n)
- Drop lower terms: O(n² + n) → O(n²)
- Different inputs use different variables: O(a + b), not O(n)

Essential Data Structures

1. Array/List

# Python
arr = [1, 2, 3]
arr.append(4)        # O(1)
arr.pop()            # O(1)
arr.insert(0, 0)     # O(n)
arr[0]               # O(1) access

2. Hash Map (Dictionary)

# Python
map = {}
map['key'] = 'value'  # O(1)
if 'key' in map:      # O(1)
    val = map['key']  # O(1)

3. Set

# Python
s = set()
s.add(1)              # O(1)
if 1 in s:            # O(1)
    s.remove(1)       # O(1)

4. Stack (List as Stack)

# Python
stack = []
stack.append(1)       # Push - O(1)
top = stack[-1]       # Peek - O(1)
stack.pop()           # Pop - O(1)

5. Queue (deque)

from collections import deque
q = deque()
q.append(1)           # Enqueue - O(1)
q.popleft()           # Dequeue - O(1)

6. Heap (Priority Queue)

import heapq
heap = []
heapq.heappush(heap, 3)   # O(log n)
min_val = heapq.heappop(heap)  # O(log n)

🎯 Pattern 1: Arrays & Hashing

When to Use:

  • Need O(1) lookup
  • Counting frequency
  • Finding duplicates
  • Grouping related items

Key Concepts:

  • Hash maps for O(1) lookup
  • Sets for uniqueness
  • Array as hash (limited range)

Problem 1: Two Sum ⭐ EASY

LeetCode #1

Problem:

Given array of integers and target, return indices of two numbers that add up to target.

Input: nums = [2,7,11,15], target = 9
Output: [0,1]  (because nums[0] + nums[1] = 9)

Approach:
- Use hash map to store (value → index)
- For each number, check if (target - number) exists in map

Solution:

def twoSum(nums, target):
    seen = {}  # value → index

    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i

    return []

# Time: O(n), Space: O(n)

Key Insight: One-pass solution using hash map to remember previous values.

Return true if any value appears at least twice.

def containsDuplicate(nums):

Problem 3: Valid Anagram ⭐ EASY

LeetCode #242

Problem:

Two strings are anagrams if they contain same characters with same frequency.

Input: s = "anagram", t = "nagaram"
Output: true

Solution 1: Sorting

def isAnagram(s, t):
    return sorted(s) == sorted(t)

# Time: O(n log n), Space: O(1)

Solution 2: Hash Map (Better)

def isAnagram(s, t):
    if len(s) != len(t):
        return False

    count = {}
    for char in s:
        count[char] = count.get(char, 0) + 1

    for char in t:
        if char not in count or count[char] == 0:
            return False
        count[char] -= 1

    return True

# Time: O(n), Space: O(1) - max 26 letters

Solution 3: Counter (Python)

from collections import Counter

def isAnagram(s, t):
    return Counter(s) == Counter(t)

Problem 4: Group Anagrams ⭐⭐ MEDIUM

LeetCode #49

Problem:

Group strings that are anagrams of each other.

Input: strs = ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]]

Approach:
- Use sorted string as key
- Group words with same sorted key

Solution:

from collections import defaultdict

def groupAnagrams(strs):
    groups = defaultdict(list)

    for s in strs:
        # Sort string to use as key
        key = ''.join(sorted(s))
        groups[key].append(s)

    return list(groups.values())

# Time: O(n * k log k) where k = avg string length
# Space: O(n * k)

Optimization (Character Count Key):

def groupAnagrams(strs):
    groups = defaultdict(list)

    for s in strs:
        # Use character count as key
        count = [0] * 26
        for char in s:
            count[ord(char) - ord('a')] += 1

        key = tuple(count)
        groups[key].append(s)

    return list(groups.values())

# Time: O(n * k), Space: O(n * k)

Problem 5: Product of Array Except Self ⭐⭐ MEDIUM

LeetCode #238

Problem:

Return array where output[i] = product of all elements except nums[i].
Cannot use division.

Input: nums = [1,2,3,4]
Output: [24,12,8,6]

Approach:
- Left pass: accumulate products from left
- Right pass: accumulate products from right

Solution:

def productExceptSelf(nums):
    n = len(nums)
    result = [1] * n

    # Left pass
    left = 1
    for i in range(n):
        result[i] = left
        left *= nums[i]

    # Right pass
    right = 1
    for i in range(n - 1, -1, -1):
        result[i] *= right
        right *= nums[i]

    return result

# Time: O(n), Space: O(1) - output doesn't count

Example walkthrough:

nums   = [1, 2, 3, 4]

After left pass:
result = [1, 1, 2, 6]
         ↑  ↑  ↑  ↑
         1  1  1*2  1*2*3

After right pass:
result = [24, 12, 8, 6]
         ↑   ↑   ↑  ↑
         1*2*3*4 from right side

Problem 6: Top K Frequent Elements ⭐⭐ MEDIUM

LeetCode #347

Problem:

Return k most frequent elements.

Input: nums = [1,1,1,2,2,3], k = 2
Output: [1,2]

Solution 1: Heap

import heapq
from collections import Counter

def topKFrequent(nums, k):
    count = Counter(nums)
    # Heap of (-frequency, num) to get max heap behavior
    return [num for num, freq in count.most_common(k)]

# Time: O(n log k), Space: O(n)

Solution 2: Bucket Sort (Optimal)

def topKFrequent(nums, k):
    count = {}
    for num in nums:
        count[num] = count.get(num, 0) + 1

    # Bucket: index = frequency, value = list of numbers
    buckets = [[] for _ in range(len(nums) + 1)]
    for num, freq in count.items():
        buckets[freq].append(num)

    # Collect from highest frequency
    result = []
    for i in range(len(buckets) - 1, 0, -1):
        result.extend(buckets[i])
        if len(result) >= k:
            return result[:k]

    return result

# Time: O(n), Space: O(n)

Problem 7: Encode and Decode Strings ⭐⭐ MEDIUM

LeetCode #271 (Premium)

Problem:

Design algorithm to encode list of strings to single string,
and decode back to original list.

Input: ["hello","world"]
Encoded: "5#hello5#world"
Decoded: ["hello","world"]

Solution:

def encode(strs):
    # Format: length + '#' + string
    return ''.join(f"{len(s)}#{s}" for s in strs)

def decode(s):
    result = []
    i = 0

    while i < len(s):
        # Find delimiter
        j = i
        while s[j] != '#':
            j += 1

        # Extract length
        length = int(s[i:j])

        # Extract string
        result.append(s[j+1 : j+1+length])

        # Move to next
        i = j + 1 + length

    return result

# Time: O(n), Space: O(1) - excluding output

Problem 8: Longest Consecutive Sequence ⭐⭐ MEDIUM

LeetCode #128

Problem:

Find length of longest consecutive sequence. Must be O(n).

Input: nums = [100,4,200,1,3,2]
Output: 4  (sequence: [1,2,3,4])

Approach:
- Use set for O(1) lookup
- Only start counting from sequence starts
- A number is a sequence start if (num - 1) doesn't exist

Solution:

def longestConsecutive(nums):
    num_set = set(nums)
    longest = 0

    for num in num_set:
        # Only count if this is start of sequence
        if num - 1 not in num_set:
            current = num
            length = 1

            # Count consecutive numbers
            while current + 1 in num_set:
                current += 1
                length += 1

            longest = max(longest, length)

    return longest

# Time: O(n), Space: O(n)

Key Insight: Each number visited at most twice (once as start, once in a sequence).

Problem 9: Valid Palindrome ⭐ EASY

LeetCode #125

Problem:

Check if string is palindrome (ignore non-alphanumeric, case-insensitive).

Input: s = "A man, a plan, a canal: Panama"
Output: true

Solution:

def isPalindrome(s):
    left, right = 0, len(s) - 1

    while left < right:
        # Skip non-alphanumeric
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1

        # Compare
        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True

# Time: O(n), Space: O(1)

Problem 10: Two Sum II (Sorted Array) ⭐ EASY

LeetCode #167

Problem:

Find two numbers in SORTED array that add up to target.
Return 1-indexed positions.

Input: numbers = [2,7,11,15], target = 9
Output: [1,2]

Solution:

def twoSum(numbers, target):
    left, right = 0, len(numbers) - 1

    while left < right:
        current_sum = numbers[left] + numbers[right]

        if current_sum == target:
            return [left + 1, right + 1]  # 1-indexed
        elif current_sum < target:
            left += 1  # Need larger sum
        else:
            right -= 1  # Need smaller sum

    return []

# Time: O(n), Space: O(1)

Key Insight: Because array is sorted, we can decide which pointer to move.

Problem 11: 3Sum ⭐⭐ MEDIUM

LeetCode #15

Problem:

Find all unique triplets that sum to zero.

Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]

Approach:
- Sort array
- Fix one number, use two pointers for the other two
- Skip duplicates

Solution:

def threeSum(nums):
    nums.sort()
    result = []

    for i in range(len(nums) - 2):
        # Skip duplicates for first number
        if i > 0 and nums[i] == nums[i-1]:
            continue

        # Two pointers for remaining two numbers
        left, right = i + 1, len(nums) - 1
        target = -nums[i]

        while left < right:
            current_sum = nums[left] + nums[right]

            if current_sum == target:
                result.append([nums[i], nums[left], nums[right]])

                # Skip duplicates for second number
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                # Skip duplicates for third number
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1

                left += 1
                right -= 1
            elif current_sum < target:
                left += 1
            else:
                right -= 1

    return result

# Time: O(n²), Space: O(1) - excluding output

Problem 12: Container With Most Water ⭐⭐ MEDIUM

LeetCode #11

Problem:

Find two lines that together with x-axis form container with most water.

Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49  (between height[1]=8 and height[8]=7)

Approach:
- Start with widest container (left=0, right=n-1)
- Move pointer with smaller height (bottleneck)

Solution:

def maxArea(height):
    left, right = 0, len(height) - 1
    max_water = 0

    while left < right:
        # Calculate area
        width = right - left
        h = min(height[left], height[right])
        max_water = max(max_water, width * h)

        # Move pointer with smaller height
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return max_water

# Time: O(n), Space: O(1)

Why this works:
- If we move the taller line, width decreases and height can't increase
- If we move the shorter line, width decreases but height might increase

Problem 13: Trapping Rain Water ⭐⭐⭐ HARD

LeetCode #42

Problem:

Compute how much water can be trapped after rain.

Input: height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6

Approach:
- Water trapped at position = min(max_left, max_right) - height[i]
- Use two pointers, track left_max and right_max

Solution:

def trap(height):
    if not height:
        return 0

    left, right = 0, len(height) - 1
    left_max, right_max = height[left], height[right]
    water = 0

    while left < right:
        if left_max < right_max:
            left += 1
            left_max = max(left_max, height[left])
            water += left_max - height[left]
        else:
            right -= 1
            right_max = max(right_max, height[right])
            water += right_max - height[right]

    return water

# Time: O(n), Space: O(1)

🎯 Pattern 3: Sliding Window

When to Use:

  • Subarray/substring problems
  • Need to track range of elements
  • Optimize from O(n²) to O(n)

Key Concepts:

  • Expand window (move right)
  • Contract window (move left)
  • Track state in window (hash map, variables)

Problem 14: Best Time to Buy and Sell Stock ⭐ EASY

LeetCode #121

Problem:

Find max profit from one buy and one sell.

Input: prices = [7,1,5,3,6,4]
Output: 5  (buy at 1, sell at 6)

Solution:

def maxProfit(prices):
    min_price = float('inf')
    max_profit = 0

    for price in prices:
        min_price = min(min_price, price)
        profit = price - min_price
        max_profit = max(max_profit, profit)

    return max_profit

# Time: O(n), Space: O(1)

Problem 15: Longest Substring Without Repeating Characters ⭐⭐ MEDIUM

LeetCode #3

Problem:

Find length of longest substring without repeating characters.

Input: s = "abcabcbb"
Output: 3  ("abc")

Solution:

def lengthOfLongestSubstring(s):
    char_index = {}  # character → last seen index
    left = 0
    max_length = 0

    for right, char in enumerate(s):
        # If char seen and in current window
        if char in char_index and char_index[char] >= left:
            left = char_index[char] + 1

        char_index[char] = right
        max_length = max(max_length, right - left + 1)

    return max_length

# Time: O(n), Space: O(min(n, alphabet_size))

Problem 16: Longest Repeating Character Replacement ⭐⭐ MEDIUM

LeetCode #424

Problem:

Can replace at most k characters. Find longest substring with same letter.

Input: s = "AABABBA", k = 1
Output: 4  ("AABA" or "ABBB")

Approach:
- Sliding window
- Track most frequent character in window
- If window_size - max_freq > k, shrink window

Solution:

def characterReplacement(s, k):
    count = {}
    left = 0
    max_freq = 0
    max_length = 0

    for right, char in enumerate(s):
        count[char] = count.get(char, 0) + 1
        max_freq = max(max_freq, count[char])

        # If need more than k replacements, shrink window
        window_size = right - left + 1
        if window_size - max_freq > k:
            count[s[left]] -= 1
            left += 1

        max_length = max(max_length, right - left + 1)

    return max_length

# Time: O(n), Space: O(1) - max 26 letters

Problem 17: Minimum Window Substring ⭐⭐⭐ HARD

LeetCode #76

Problem:

Find minimum window in s that contains all characters of t.

Input: s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"

Solution:

from collections import Counter

def minWindow(s, t):
    if not s or not t:
        return ""

    target = Counter(t)
    required = len(target)
    formed = 0

    window_counts = {}
    left, right = 0, 0
    min_len = float('inf')
    min_left = 0

    while right < len(s):
        # Expand window
        char = s[right]
        window_counts[char] = window_counts.get(char, 0) + 1

        if char in target and window_counts[char] == target[char]:
            formed += 1

        # Contract window
        while left <= right and formed == required:
            # Update result
            if right - left + 1 < min_len:
                min_len = right - left + 1
                min_left = left

            # Remove from left
            char = s[left]
            window_counts[char] -= 1
            if char in target and window_counts[char] < target[char]:
                formed -= 1
            left += 1

        right += 1

    return "" if min_len == float('inf') else s[min_left:min_left + min_len]

# Time: O(|s| + |t|), Space: O(|s| + |t|)

Problem 18: Valid Parentheses ⭐ EASY

LeetCode #20

Problem:

Check if brackets are properly nested.

Input: s = "()[]{}"
Output: true

Input: s = "([)]"
Output: false

Solution:

def isValid(s):
    stack = []
    mapping = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in mapping:
            # Closing bracket
            if not stack or stack[-1] != mapping[char]:
                return False
            stack.pop()
        else:
            # Opening bracket
            stack.append(char)

    return len(stack) == 0

# Time: O(n), Space: O(n)

Problem 19: Min Stack ⭐⭐ MEDIUM

LeetCode #155

Problem:

Design stack that supports push, pop, top, and getMin in O(1).

Solution:

class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val):
        self.stack.append(val)
        # Store current minimum
        if not self.min_stack:
            self.min_stack.append(val)
        else:
            self.min_stack.append(min(val, self.min_stack[-1]))

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]

# All operations: O(1) time, O(n) space

Problem 20: Evaluate Reverse Polish Notation ⭐⭐ MEDIUM

LeetCode #150

Problem:

Evaluate expression in Reverse Polish Notation.

Input: tokens = ["2","1","+","3","*"]
Output: 9  ((2 + 1) * 3)

Solution:

def evalRPN(tokens):
    stack = []
    operators = {'+', '-', '*', '/'}

    for token in tokens:
        if token in operators:
            b = stack.pop()
            a = stack.pop()

            if token == '+':
                stack.append(a + b)
            elif token == '-':
                stack.append(a - b)
            elif token == '*':
                stack.append(a * b)
            else:  # division
                # Truncate toward zero
                stack.append(int(a / b))
        else:
            stack.append(int(token))

    return stack[0]

# Time: O(n), Space: O(n)

Problem 21: Binary Search ⭐ EASY

LeetCode #704

Problem:

Search for target in sorted array.

Input: nums = [-1,0,3,5,9,12], target = 9
Output: 4

Solution:

def search(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1

Problem 22: Search in Rotated Sorted Array ⭐⭐ MEDIUM

Problem:

Search in rotated sorted array.

Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4

Solution:

def search(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid

        # Determine which half is sorted
        if nums[left] <= nums[mid]:
            # Left half is sorted
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            # Right half is sorted
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1

    return -1

# Time: O(log n), Space: O(1)

Problem 34: Binary Tree Level Order Traversal ⭐⭐ MEDIUM

Problem:

Return level-order traversal (BFS).

Input:     3
         /   \
        9     20
             /  \
            15   7

Output: [[3], [9,20], [15,7]]

Solution:

from collections import deque

def levelOrder(root):
    if not root:
        return []

    result = []
    queue = deque([root])

    while queue:
        level_size = len(queue)
        level = []

        for _ in range(level_size):
            node = queue.popleft()
            level.append(node.val)

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

        result.append(level)

    return result

# Time: O(n), Space: O(n)

Implement Trie with insert, search, startsWith.

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True

    def search(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end

    def startsWith(self, prefix):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True

# Insert: O(n), Search: O(n), Space: O(total chars)

Problem 39: Design Add and Search Words ⭐⭐ MEDIUM

Problem:

Design data structure that supports:
- addWord(word)
- search(word) - word can contain '.' for any character

    def __init__(self):
        self.children = {}
        self.is_end = False

class WordDictionary:
    def __init__(self):
        self.root = TrieNode()

    def addWord(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True

    def search(self, word):
        return self.dfs(word, 0, self.root)

    def dfs(self, word, index, node):
        if index == len(word):
            return node.is_end

        char = word[index]

        if char == '.':
            # Try all children
            for child in node.children.values():
                if self.dfs(word, index + 1, child):
                    return True
            return False
        else:
            if char not in node.children:
                return False
            return self.dfs(word, index + 1, node.children[char])

    def __init__(self, k, nums):
        self.k = k
        self.heap = nums
        heapq.heapify(self.heap)

        while len(self.heap) > k:

Problem 41: Find Median from Data Stream ⭐⭐⭐ HARD

LeetCode #295

Problem:

Design data structure that supports:
- addNum(num)
- findMedian() - return median of all numbers

addNum(1)
addNum(2)
findMedian() → 1.5
addNum(3)
findMedian() → 2

Approach:
- Use two heaps:
- Max heap for smaller half
- Min heap for larger half
- Keep heaps balanced

Solution:

import heapq

class MedianFinder:
    def __init__(self):
        # Max heap (invert values)
        self.small = []
        # Min heap
        self.large = []

    def addNum(self, num):
        # Add to small (max heap)
        heapq.heappush(self.small, -num)

        # Balance: largest in small <= smallest in large
        if self.small and self.large and -self.small[0] > self.large[0]:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)

        # Balance sizes
        if len(self.small) > len(self.large) + 1:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)
        if len(self.large) > len(self.small):
            val = heapq.heappop(self.large)
            heapq.heappush(self.small, -val)

    def findMedian(self):
        if len(self.small) > len(self.large):
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2.0

# addNum: O(log n), findMedian: O(1)

Problem 42: Combination Sum ⭐⭐ MEDIUM

Find all combinations that sum to target. Can reuse numbers.

Input: candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]

Solution:

def combinationSum(candidates, target):
    result = []

    def backtrack(start, path, remaining):
        if remaining == 0:
            result.append(path[:])
            return
        if remaining < 0:
            return

        for i in range(start, len(candidates)):
            path.append(candidates[i])
            # Can reuse same number
            backtrack(i, path, remaining - candidates[i])
            path.pop()

    backtrack(0, [], target)
    return result

# Time: O(2^target), Space: O(target)

Problem 43: Word Search ⭐⭐ MEDIUM

LeetCode #79

Problem:

Find if word exists in grid. Can move up/down/left/right.

board = [["A","B","C","E"],
         ["S","F","C","S"],
         ["A","D","E","E"]]

word = "ABCCED" → true
word = "SEE" → true
word = "ABCB" → false

Solution:

def exist(board, word):
    rows, cols = len(board), len(board[0])

    def backtrack(r, c, index):
        # Found word
        if index == len(word):
            return True

        # Out of bounds or wrong character
        if (r < 0 or r >= rows or c < 0 or c >= cols or
            board[r][c] != word[index]):
            return False

        # Mark visited
        temp = board[r][c]
        board[r][c] = '#'

        # Try all 4 directions
        found = (backtrack(r+1, c, index+1) or
                 backtrack(r-1, c, index+1) or
                 backtrack(r, c+1, index+1) or
                 backtrack(r, c-1, index+1))

        # Restore
        board[r][c] = temp

        return found

    for r in range(rows):
        for c in range(cols):
            if backtrack(r, c, 0):
                return True
    return False

# Time: O(n * m * 4^L) where L = word length

Problem 46: Course Schedule ⭐⭐ MEDIUM

Problem:

Can you finish all courses given prerequisites?

Output: true  (take course 0 first, then 1)

Output: false  (cycle)

Approach: Detect cycle in directed graph using DFS.

Solution:

def canFinish(numCourses, prerequisites):
    # Build adjacency list
    graph = {i: [] for i in range(numCourses)}
    for course, prereq in prerequisites:
        graph[course].append(prereq)

    # 0 = unvisited, 1 = visiting, 2 = visited
    state = [0] * numCourses

    def has_cycle(course):
        if state[course] == 1:
            # Visiting again = cycle
            return True
        if state[course] == 2:
            # Already checked
            return False

        # Mark as visiting
        state[course] = 1

        # Check prerequisites
        for prereq in graph[course]:
            if has_cycle(prereq):
                return True

        # Mark as visited
        state[course] = 2
        return False

    for course in range(numCourses):
        if has_cycle(course):
            return False

    return True

# Time: O(V + E), Space: O(V + E)

Water flows from high to low or equal height.

      ~ 1 2 2 3 (5) *
      ~ 3 2 3 (4) (4) *
      ~ 2 4 (5) 3 1 *
      ~ (6) (7) 1 4 5 *
      ~ (5) 1 1 2 4 *
         * * * * * Atlantic

- DFS from both oceans
- Find cells reachable by both

def pacificAtlantic(heights):
    if not heights:
        return []

    rows, cols = len(heights), len(heights[0])
    pacific = set()
    atlantic = set()

    def dfs(r, c, visited):
        if (r, c) in visited:
            return
        visited.add((r, c))

        for dr, dc in [(0,1), (0,-1), (1,0), (-1,0)]:
            nr, nc = r + dr, c + dc
            if (0 <= nr < rows and 0 <= nc < cols and
                heights[nr][nc] >= heights[r][c]):
                dfs(nr, nc, visited)

    for c in range(cols):
        dfs(0, c, pacific)
        dfs(rows-1, c, atlantic)
    for r in range(rows):
        dfs(r, 0, pacific)
        dfs(r, cols-1, atlantic)

    # Find intersection
    return list(pacific & atlantic)

Output: 4  ([2,3,7,101] or [2,3,7,18])

Solution (DP):

def lengthOfLIS(nums):
    if not nums:
        return 0

    # dp[i] = length of LIS ending at i
    dp = [1] * len(nums)

    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)

# Time: O(n²), Space: O(n)

Problem 51: Coin Change ⭐⭐ MEDIUM

LeetCode #322

Problem:

Fewest coins to make amount. Each coin can be used unlimited times.

Input: coins = [1,2,5], amount = 11
Output: 3  (5 + 5 + 1)

Solution:

def coinChange(coins, amount):
    # dp[i] = fewest coins to make amount i
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0

    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)

    return dp[amount] if dp[amount] != float('inf') else -1

# Time: O(amount * len(coins)), Space: O(amount)

Problem 52: Longest Common Subsequence ⭐⭐ MEDIUM

LeetCode #1143

Problem:

Find length of LCS between two strings.

Input: text1 = "abcde", text2 = "ace"
Output: 3  ("ace")

Solution:

def longestCommonSubsequence(text1, text2):
    m, n = len(text1), len(text2)

    # dp[i][j] = LCS of text1[0:i] and text2[0:j]
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = 1 + dp[i-1][j-1]
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]

# Time: O(m * n), Space: O(m * n)

Problem 53: Word Break ⭐⭐ MEDIUM

LeetCode #139

Problem:

Can string be segmented into dictionary words?

Input: s = "leetcode", wordDict = ["leet","code"]
Output: true

Solution:

def wordBreak(s, wordDict):
    word_set = set(wordDict)
    n = len(s)

    # dp[i] = can we break s[0:i]
    dp = [False] * (n + 1)
    dp[0] = True

    for i in range(1, n + 1):
        for j in range(i):
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break

    return dp[n]

# Time: O(n² * m) where m = avg word length
# Space: O(n + k) where k = dict size

Problem 54: Unique Paths ⭐⭐ MEDIUM

LeetCode #62

Problem:

How many unique paths in m x n grid from top-left to bottom-right?
Can only move right or down.

Input: m = 3, n = 7
Output: 28

Solution:

def uniquePaths(m, n):
    # dp[i][j] = paths to reach (i, j)
    dp = [[1] * n for _ in range(m)]

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i-1][j] + dp[i][j-1]

    return dp[m-1][n-1]

# Time: O(m * n), Space: O(m * n)
# Can optimize to O(n) space

Problem 55: Jump Game ⭐⭐ MEDIUM

LeetCode #55

Problem:

Can you reach last index? Each element is max jump length.

Input: nums = [2,3,1,1,4]
Output: true  (jump 1 to index 1, then 3 to end)

Solution (Greedy):

def canJump(nums):
    max_reach = 0

    for i in range(len(nums)):
        if i > max_reach:
            return False
        max_reach = max(max_reach, i + nums[i])
        if max_reach >= len(nums) - 1:
            return True

    return True

# Time: O(n), Space: O(1)
