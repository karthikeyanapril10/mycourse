What to Add:

6. Experience Section 💼

CRITICAL: Must match your resume exactly (dates, titles, company names)

For Each Job:

  1. Job Title: Same as resume
  2. Company Name: Same as resume
  3. Dates: Same as resume (Month Year - Month Year)
  4. Description: Copy from resume, but you can add MORE detail on LinkedIn

LinkedIn-Specific Tips:
- Add 1-2 extra bullets not in resume (LinkedIn has more space)
- Use first-person ("I led...") or drop "I" ("Led...")
- Add media: Screenshots of dashboards, architecture diagrams, certificates

Production Support Engineer / Systems Reliability

⚠️ Common LinkedIn Mistakes to Avoid

  1. ❌ Headline = Current job title only ("Production Support Engineer")
    - ✅ FIX: Add skills + years + location

  2. ❌ About section = Resume copy-paste
    - ✅ FIX: Make it conversational, add personality

  3. ❌ No profile photo
    - ✅ FIX: Any professional photo > no photo

  4. ❌ Skills randomly ordered
    - ✅ FIX: Top 3 = most important keywords (PHP, Laravel, Python)

  5. ❌ Not asking for recommendations
    - ✅ FIX: Message 3 former managers/colleagues today

  6. ❌ Zero activity (no posts, no comments)
    - ✅ FIX: Comment on 1 post/day minimum
