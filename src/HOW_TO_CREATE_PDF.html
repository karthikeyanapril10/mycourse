How to Create PDF from HTML Resume

📄 Quick Steps (5 minutes)

Method 1: Chrome/Edge Browser (Recommended) ⭐

  1. Open the HTML file:
    - Go to: C:\Users\kasekar\GH\interview-prep\
    - Double-click: Karthikeyan_Sekar_Resume_ATS_Optimized.html
    - Opens in your default browser (Chrome/Edge)

  2. Print to PDF:
    - Press Ctrl + P (Print dialog opens)
    - Destination: Click "Change" → Select "Save as PDF"
    - Layout: Portrait
    - Pages: All
    - Margins: Default
    - Click "Save"

  3. Save the PDF:
    - File name: Karthikeyan_Sekar_Senior_Engineer_12yrs.pdf
    - Location: Same folder (C:\Users\kasekar\GH\interview-prep\)
    - Click "Save"

✅ Done! Your ATS-optimized PDF resume is ready.

Method 2: Microsoft Word (Alternative)

  1. Open Word → File → Open → Select the HTML file
  2. File → Save As → Select "PDF" from dropdown
  3. Save as: Karthikeyan_Sekar_Senior_Engineer_12yrs.pdf

Method 3: Online Converter (If above don't work)

  1. Go to: https://www.sejda.com/html-to-pdf
  2. Upload: Karthikeyan_Sekar_Resume_ATS_Optimized.html
  3. Click "Convert to PDF"
  4. Download the PDF

✅ Verify Your PDF

Open the PDF and check:
- [ ] All text is readable (not cut off)
- [ ] Formatting looks professional
- [ ] Contact info at top (phone, email, LinkedIn)
- [ ] All sections visible (Summary, Skills, Experience, Projects, Education)
- [ ] Page breaks look good (not cutting bullets mid-sentence)
- [ ] File size < 1 MB (for easy email/upload)

Expected: 2 pages, ~300-400 KB file size

🎯 File Naming Best Practices

Good: ✅
- Karthikeyan_Sekar_Senior_Engineer_12yrs.pdf
- Karthikeyan_Sekar_Resume_2026.pdf
- KarthikeyanSekar_FullStack_Resume.pdf

Bad: ❌
- Resume.pdf
- My Resume Final.pdf
- New_Resume_v3_updated.pdf

Why: Recruiters save hundreds of resumes — yours should be instantly identifiable.

📱 Test Your PDF on Mobile

  1. Email the PDF to yourself
  2. Open on your phone
  3. Check if it's readable (zoom not needed)
  4. Verify links work (LinkedIn URL)

Why: Many recruiters review resumes on mobile first.

🔄 When to Update Your PDF

Update when:
- ✅ You get AWS certification (add to Certifications section)
- ✅ You complete a major project (add to Projects)
- ✅ You change jobs (update Experience)
- ✅ You learn a new major technology (add to Skills)

Don't update for:
- ❌ Minor wording changes
- ❌ Fixing one typo (unless in your name/contact info!)
- ❌ Just to have "latest version" (update only when substance changes)

Best Practice: Keep 1 master version, update monthly if job searching actively.
