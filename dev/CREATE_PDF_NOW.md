# 📄 CREATE YOUR PDF RESUME - 3 SIMPLE STEPS

**Your beautiful resume is OPEN in your browser right now!**

---

## ✅ Step 1: Press Ctrl + P

**On your keyboard, press:** `Ctrl + P`

This will open the Print dialog.

---

## ✅ Step 2: Select "Save as PDF"

In the Print dialog:

1. **Destination:** Click the dropdown
2. Select: **"Save as PDF"** or **"Microsoft Print to PDF"**

**Settings (verify these):**
- Layout: **Portrait**
- Pages: **All**
- Margins: **Default**
- Scale: **Default** (100%)

---

## ✅ Step 3: Save the PDF

1. Click **"Save"** button
2. **File name:** Type this exactly:
   ```
   Karthikeyan_Sekar_Resume_2026
   ```
3. **Save location:** Keep it in the same folder:
   ```
   C:\Users\kasekar\GH\interview-prep\
   ```
4. Click **"Save"**

## ⚠️ Troubleshooting

**If the Print dialog doesn't appear:**
- Try: `Ctrl + P` again
- Or: Click browser menu (⋮) → Print

**If colors don't appear in PDF:**
- In Print dialog, check: **"Background graphics"** ✓

**If it's more than 2 pages:**
- Check Scale is **100%** (not 90% or 110%)
